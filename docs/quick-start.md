# Quick start

## 1. Start the app

After buying the Windows edition on [itch.io](https://clickmacroassistant.itch.io/clickmacro-assistant), download the ZIP, extract it to a folder, and run `ClickMacroAssistant.exe`. No installer or Python setup is needed. The app starts in English; choose another language from the main window's lower-left selector.

## 2. Try the multi-point clicker

In the automatic points area, use **Pick point (3 s)** and move your pointer to the target before the countdown ends. Select a point action, set the interval and number of cycles, then press **Start**. **F8** starts or stops the main clicker; **F9** is its emergency stop. Hotkey points are a separate list that runs one pass each time the configured trigger is pressed. You can save and load point lists as `.dat` files.

## 3. Try Automation Studio

Open **Automation Studio**, choose **Record**, and perform a short, harmless action in Notepad. Press **F6** to end recording. Restore Notepad and the desktop to the same starting state, then press **F7** to replay. **F10** stops a Studio task. Studio also supports selected-step replay and editing. Save and load macro step lists as `.mcs` files.

## 4. For image steps and schedules

An image step uses a BMP file on your computer. When moving a macro to another computer, keep the BMP accessible and update its path if needed. Scheduled runs work only while the computer and app remain running.

## 5. Check the result

Replay can differ when windows move, menus appear late, file names change, or the computer responds at a different speed. Start with disposable test files. Keep the full guide included in your purchase nearby for detailed instructions.
